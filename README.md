# MPVKit

[![mpv](https://img.shields.io/badge/mpv-v0.41.0-blue.svg)](https://github.com/mpv-player/mpv)
[![ffmpeg](https://img.shields.io/badge/ffmpeg-n8.0.1-blue.svg)](https://github.com/FFmpeg/FFmpeg)
[![license](https://img.shields.io/github/license/mpvkit/MPVKit)](https://github.com/mpvkit/MPVKit/main/LICENSE)

> MPVKit is only suitable for learning `libmpv` and will not be maintained too frequently.

`MPVKit` is a collection of tools to use `mpv` in `iOS`, `macOS`, `tvOS` applications.

It includes scripts to build `mpv` native libraries.

Forked from [kingslay/FFmpegKit](https://github.com/kingslay/FFmpegKit)

## About Metal support

Metal support only a patch version ([#7857](https://github.com/mpv-player/mpv/pull/7857)) and does not officially support it yet. Encountering any issues is not strange.

## How to build

```bash
make build
# specified platforms (ios,macos,tvos,tvsimulator,isimulator,maccatalyst,xros,xrsimulator)
make build platform=ios,macos
# clean all build temp files and cache
make clean
# see help
make help
```

`make build` links every static library it produces into one dynamic
`MPVKit.xcframework` (see `Sources/BuildScripts/XCFrameworkBuild/merge.swift`),
which is the only artifact the package vends. Consumers `import MPVKit`.

**The checkout path must not contain an apostrophe.** pkg-config shell-parses the
`Libs:` field of a `.pc` file, so a prefix such as `/Users/you/Ben's Drive/...`
fails with *"Couldn't parse Libs field into an argument vector"* and every
dependency lookup misses. The `.pc` files are generated by each library's own
build, so this cannot be worked around in these scripts -- build from a path
without one. A space in the path is fine.

If Xcode is not the active developer directory, `DEVELOPER_DIR` is honoured:

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer make build
```

## Run default mpv player

```bash
./mpv.sh --input-commands='script-message display-stats-toggle' [url]
./mpv.sh --list-options
```

> Use <kbd>Shift</kbd>+<kbd>i</kbd> to show stats overlay
